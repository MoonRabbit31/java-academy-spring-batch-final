Proyecto Final Spring

El proyecto está totalmente ordenado y listo para ser copiado y ejecutado, el único cambio 
que podría ocurrir es en el application properties y es el único archivo
del proyecto que se deberá modiificar de ser necesario.
1.- tener docker y los contenedores corriendo
2.- Los puertos usados son 3306 para SQL y 27017 para mongodb, en caso que los
contenedores estén en otro puerto, modificar el archivo.
3.- cambiar el spring.batch.job.enabled=false a true, correr spring y luego pasarlo a false

Con ello se tendría corriendo el entorno de forma correcta.
